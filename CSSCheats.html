🎨 Шпаргалка по CSS

Основные свойства и селекторы для стилизации

1. Подключение CSS к HTML

Внутренние стили (в head):

<style>
    selector {
        property: value;
    }
</style>

Внешний файл (рекомендуется):

<link rel="stylesheet" href="styles.css">

Инлайн-стили (в теге):

<div style="color: red;">Текст</div>
Приоритет: Инлайн > Внутренние > Внешние > Браузерные

2. Основные селекторы

* {
    margin: 0;
    padding: 0;
}

#id {
    color: red;
}

.class {
    font-size: 16px;
}

div {
    border: 1px solid #000;
}

div.class {
    background: #fff;
}

selector1, selector2 {
    margin: 10px;
}

3. Комбинированные селекторы

div p — все <p> внутри <div>
div > p — только прямые дочерние <p>
h1 + p — первый <p> после <h1>
h1 ~ p — все <p> после <h1>
a:hover — при наведении
input:focus — при фокусе
li:first-child — первый элемент
li:nth-child(3) — третий элемент
li:nth-child(odd) — нечетные элементы

Пример:

nav a:hover {
    color: red;
    text-decoration: underline;
}

tr:nth-child(even) {
    background-color: #f2f2f2;
}

4. Box Model (Блочная модель)

Margin (внешний отступ)
Border (рамка)
Padding (внутренний отступ)
Content (контент)
.box {
    width: 200px;
    height: 100px;
    padding: 20px;
    border: 2px solid black;
    margin: 10px;
    box-sizing: border-box; /* включает padding и border в width */
}

5. Работа с текстом

p {
    color: #333;
    font-family: Arial, sans-serif;
    font-size: 16px;
    font-weight: bold; /* normal, bold, 100-900 */
    font-style: italic;
    text-align: center; /* left, right, justify */
    line-height: 1.5;
    text-decoration: underline; /* none, line-through */
    text-transform: uppercase; /* lowercase, capitalize */
    letter-spacing: 1px;
    word-spacing: 2px;
}

6. Цвета и фон

Способы задания цвета:

color: red; — ключевое слово
color: #ff0000; — HEX
color: #f00; — сокращенный HEX
color: rgb(255, 0, 0); — RGB
color: rgba(255, 0, 0, 0.5); — RGB + прозрачность
color: hsl(0, 100%, 50%); — HSL

Фон:

.element {
    background-color: #f0f0f0;
    background-image: url('image.jpg');
    background-repeat: no-repeat; /* repeat, repeat-x, repeat-y */
    background-position: center center;
    background-size: cover; /* contain, 100% 100% */
    background: #f0f0f0 url('img.jpg') no-repeat center; /* сокращенная запись */
}

7. Flexbox

Контейнер (родитель):

.container {
    display: flex;
    flex-direction: row; /* column, row-reverse, column-reverse */
    justify-content: center; /* flex-start, flex-end, space-between, space-around */
    align-items: center; /* flex-start, flex-end, stretch, baseline */
    flex-wrap: wrap; /* nowrap, wrap-reverse */
    gap: 10px; /* отступ между элементами */
}

Элементы (дети):

.item {
    flex-grow: 1; /* может расти */
    flex-shrink: 0; /* может сжиматься */
    flex-basis: 100px; /* базовый размер */
    flex: 1 0 100px; /* сокращенная запись (grow shrink basis) */
    align-self: flex-end; /* переопределение align-items */
}

8. Grid

Контейнер (родитель):

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr); /* 3 колонки */
    grid-template-rows: 100px auto;
    gap: 20px; /* отступы */
    grid-template-areas: 
        "header header header"
        "sidebar content content";
}

Элементы (дети):

.item {
    grid-column-start: 1;
    grid-column-end: 3;
    grid-row: 1 / 3; /* сокращенная запись */
    grid-area: header; /* имя области */
}
Единицы: fr — доля свободного пространства, auto — автоматический размер

9. Позиционирование

position: static; — по умолчанию
position: relative; — относительно своего места
position: absolute; — относительно ближайшего позиционированного родителя
position: fixed; — относительно окна браузера
position: sticky; — липкое позиционирование 
.element {
    position: absolute;
    top: 10px;
    right: 20px;
    z-index: 10; /* порядок наложения */
}

.sticky {
    position: sticky;
    top: 0;
}

10. Анимации и переходы

Transition (переход):

.button {
    transition: all 0.3s ease;
    transition-property: background-color, transform;
    transition-duration: 0.3s;
    transition-timing-function: ease; /* linear, ease-in, ease-out */
    transition-delay: 0.1s;
}

Animation (анимация):

@keyframes slideIn {
    from {
        transform: translateX(-100%);
    }
    to {
        transform: translateX(0);
    }
}

.element {
    animation: slideIn 1s ease;
    animation-iteration-count: infinite; /* 1, 2, infinite */
    animation-direction: alternate; /* normal, reverse */
    animation-fill-mode: forwards; /* сохранить конечное состояние */
}
