💡 Шпаргалка: Как писать промты для DeepSeek

Структура запросов для точного создания HTML/CSS/JavaScript кода

1. Базовая структура промта

Эффективный промт должен содержать:

1. Контекст: Что вы делаете, цель проекта

2. Технические требования: HTML/CSS/JS, фреймворки

3. Дизайн и стиль: Внешний вид, цвета, анимации

4. Функционал: Что должно работать и как

5. Ограничения: Что НЕ нужно делать

6. Формат вывода: Какой код и в каком виде

Пример структурированного промта:

Контекст: Создаю лендинг для курсов по программированию

Технологии: Чистый HTML/CSS, без фреймворков

Стиль: Минимализм, синяя цветовая схема, адаптивная верстка

Функционал: Навигация, форма подписки, галерея курсов

Особые требования: Поддержка мобильных устройств

2. Указание стиля и дизайна

Что обязательно указать:

  • Цветовая палитра: Основные и акцентные цвета
  • Типографика: Шрифты, размеры, межстрочные расстояния
  • Макет: Количество колонок, расположение элементов
  • Анимации: Плавные переходы, hover-эффекты
  • Адаптивность: Как должен выглядеть на разных устройствах

Примеры правильных описаний:

"Стиль: минимализм, светлый фон (#f8f9fa), темный текст (#333)"

"Адаптивность: на мобильных 1 колонка, на планшетах 2, на десктопе 3"

"Шрифты: заголовки — Roboto, основной текст — Open Sans"

"Сделай красиво" — ❌ Слишком размыто

"Как у Apple" — ❌ Субъективно и неконкретно

3. Технические требования

Ключевые параметры:

Верстка: Flexbox / CSS Grid / Float
Препроцессоры: Sass / Less (указать, если нужно)
JavaScript: Нативный / jQuery / React / Vue
Адаптивность: Mobile-first / Desktop-first
Браузеры: Какие поддерживать
Спецификации: HTML5, CSS3, ES6+

Пример правильного указания:

"Использовать CSS Grid для основной сетки"

"JavaScript: нативный ES6+, без jQuery"

"Поддержка: последние версии Chrome, Firefox, Safari"

"Подход: Mobile-first, три брейкпоинта (360px, 768px, 1200px)"

Совет: Если вы новичок, укажите "чистый HTML/CSS/JS без фреймворков" — так будет проще учиться.

4. Структура HTML

Что нужно описать:

  • Основные секции: header, main, footer, sidebar
  • Навигация: Меню, количество пунктов, выпадающие списки
  • Контентные блоки: Заголовки, тексты, изображения
  • Формы: Какие поля, валидация
  • Медиа: Изображения, видео, слайдеры

Пример детального описания:

"Header: логотип слева, навигация справа (5 пунктов), кнопка 'Войти'"

"Hero-секция: заголовок h1, подзаголовок, две кнопки, фоновое изображение"

"Форма регистрации: имя, email, пароль, чекбокс согласия, кнопка отправки"

"Footer: 3 колонки со ссылками, копирайт, соц. сети"

5. Функционал JavaScript

Что конкретизировать:

  • Интерактивность: Что происходит при кликах, наведении
  • Валидация форм: Какие проверки, сообщения об ошибках
  • Анимации: Как и когда срабатывают
  • Работа с данными: Откуда берутся, куда отправляются
  • Состояния: Loading, success, error состояния

Примеры:

"При клике на меню-бургер появляется мобильное меню"

"Форма валидирует email и проверяет совпадение паролей"

"Слайдер автоматически переключается каждые 5 секунд"

"При отправке формы показывать индикатор загрузки"

"Сделать форму рабочей" — ❌ Неясно, что значит "рабочая"

"Добавить анимации" — ❌ Какие именно?

6. Формат вывода кода

Укажите предпочтения:

"Один HTML файл со встроенными стилями"

"Отдельные файлы: index.html, style.css, script.js"

"Встроить код прямо в ответ"

"Сначала HTML, потом CSS, потом JS"

"Добавить комментарии в код"

"Использовать семантические теги HTML5"

Пример полного запроса:

"Создай landing page в одном HTML файле со встроенными стилями и скриптом. Добавь комментарии к основным блокам. Используй семантические теги."

Про важность: Если не указать формат, код может быть выдан не в том виде, который вам удобен.

7. Чего следует избегать

❌ Расплывчатые формулировки:

"Сделай современный дизайн" — Что значит "современный"?

"Добавь красивые анимации" — Какие именно анимации?

"Сделай как у того сайта" — Какой именно сайт?

❌ Слишком много в одном запросе:

"Создай полноценный интернет-магазин с корзиной, оплатой, каталогом..." — Лучше разбить на части

✅ Лучший подход:

1. Сначала базовая структура

2. Потом стилизация

3. Затем добавление интерактивности

4. В конце — оптимизация и полировка

8. Примеры хороших и плохих промтов

❌ Плохой промт:

"Сделай сайт для пиццерии"

Проблемы: Нет структуры, дизайна, функционала

✅ Хороший промт:

"Создай landing page для пиццерии 'Маргарита' в одном HTML файле.

Дизайн: Итальянский стиль, цвета: красный (#e74c3c), белый (#fff), зеленый (#2ecc71)

Секции: 1) Шапка с лого и меню, 2) Герой-секция с названием и кнопкой заказа, 3) Меню пицц (6 позиций с картинками), 4) Форма заказа (имя, телефон, адрес, выбор пиццы), 5) Футер с контактами

Функционал: При клике на пиццу в меню — показывает детали. Форма проверяет телефон и адрес.

Технологии: Чистый HTML/CSS/JS, адаптивная верстка."

9. Уточняющие вопросы

Если я задаю уточняющие вопросы — это хорошо! Значит:

  • Я хочу понять ваши предпочтения точнее
  • Стараюсь избежать додумывания
  • Хочу дать максимально релевантный результат

Типичные уточняющие вопросы:

"Какой именно макет вы предпочитаете?"

"Нужны ли анимации при наведении на кнопки?"

"Как должны выглядеть состояния ошибок в форме?"

"Нужна ли адаптивная верстка под мобильные?"

"Какие именно данные должны отображаться в таблице?"

Совет: Отвечайте на уточняющие вопросы максимально конкретно — это сильно улучшит результат.

10. Шаблон идеального промта

📋 КОПИРУЙТЕ И ЗАПОЛНЯЙТЕ:

Проект: [Название проекта, например: Лендинг для онлайн-курсов]

Цель: [Чего хотите достичь, например: Привлечь студентов на курсы]

Технологии: [HTML/CSS/JS, фреймворки, например: Чистый HTML/CSS, без фреймворков]

Дизайн: [Стиль, цвета, например: Минимализм, основная палитра синяя (#3498db), акцентная оранжевая (#f39c12)]

Структура: [Секции, например: 1) Header, 2) Hero, 3) О курсах, 4) Преподаватели, 5) Форма регистрации, 6) Footer]

Функционал: [Что должно работать, например: Работающая форма регистрации с валидацией email]

Адаптивность: [Под какие устройства, например: Mobile-first, три брейкпоинта]

Формат вывода: [Как получить код, например: Один HTML файл со встроенными стилями и скриптом]

Особые требования: [Что важно, например: Семантическая верстка, комментарии в коде]

Итог: Чем конкретнее промт → тем точнее результат → меньше правок → быстрее разработка!
