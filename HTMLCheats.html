📄 Шпаргалка по HTML

Базовые конструкции для быстрого старта

1. Базовая структура документа

Основной каркас любого HTML-документа:

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Название страницы</title>
</head>
<body>
    <!-- Контент страницы -->
</body>
</html>

Запомни: <head> — для настроек, <body> — для видимого контента.

2. Семантические теги структуры

Теги, которые придают смысл разделам страницы:

<header> — шапка сайта
<nav> — навигационное меню
<main> — основное содержимое (один на страницу!)
<section> — логический раздел
<article> — самостоятельная статья
<aside> — боковая колонка
<footer> — подвал сайта
<div> — универсальный контейнер (без семантики)

Используй семантические теги для SEO и доступности.

3. Заголовки и текст

Заголовки (от самого важного к менее важному):

<h1> Главный заголовок (один на страницу!)
<h2> Заголовок раздела
<h3> — <h6> Подзаголовки

Текстовые элементы:

<p> — абзац
<b> vs <strong> (визуально vs семантика)
<i> vs <em> (визуально vs акцент)
<mark> — выделенный текст
<code> — код
<pre> — сохраняет форматирование

4. Ссылки и изображения

Ссылки:

<!-- Абсолютная ссылка -->
<a href="https://site.com" target="_blank">Текст ссылки</a>

<!-- Относительная -->
<a href="./page.html">Внутренняя страница</a>

<!-- Якорь -->
<a href="#section">К разделу</a>

Изображения:

<img src="путь/к/изображению.jpg" 
     alt="Описание изображения" 
     width="300" height="200">

Важно: Атрибут alt обязателен для доступности!

5. Списки

Маркированный список:

<ul>
    <li>Пункт 1</li>
    <li>Пункт 2
        <ul>
            <li>Вложенный пункт</li>
        </ul>
    </li>
</ul>

Нумерованный список:

<ol>
    <li>Первый пункт</li>
    <li>Второй пункт</li>
</ol>

6. Таблицы

<table border="1">
    <thead>
        <tr>
            <th>Заголовок 1</th>
            <th>Заголовок 2</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Данные 1</td>
            <td>Данные 2</td>
        </tr>
        <tr>
            <td colspan="2">Объединенная ячейка</td>
        </tr>
    </tbody>
</table>

Атрибуты:
colspan — объединение по горизонтали
rowspan — объединение по вертикали

7. Формы (основные элементы)

<form action="/submit" method="POST">
    <label for="name">Имя:</label>
    <input type="text" id="name" name="username">
    
    <input type="password" name="password">
    <input type="email" name="email" required>
    <input type="number" name="age" min="0">
    <input type="checkbox" id="agree">
    <label for="agree">Согласен</label>
    
    <textarea name="message" rows="4"></textarea>
    
    <select name="country">
        <option value="ru">Россия</option>
    </select>
    
    <input type="submit" value="Отправить">
</form>

8. Медиа-элементы

Аудио:

<audio controls>
    <source src="audio.mp3" type="audio/mpeg">
    Ваш браузер не поддерживает аудио.
</audio>

Видео:

<video controls width="600">
    <source src="video.mp4" type="video/mp4">
    Ваш браузер не поддерживает видео.
</video>

Iframe (встроенная страница):

<iframe src="https://site.com" 
        width="800" height="600"
        title="Описание">
</iframe>

9. Специальные символы (HTML-сущности)

&nbsp; — неразрывный пробел
&lt; — < (less than)
&gt; — > (greater than)
&amp; — & (амперсанд)
&copy; — ©
&trade; — ™
&euro; — €
&quot; — "
&apos; — '

Используются для отображения символов, которые имеют специальное значение в HTML.

10. Важные глобальные атрибуты

id="unique-id" — уникальный идентификатор
class="class1 class2" — один или несколько классов
style="color: red;" — инлайн-стили (лучше избегать)
title="Подсказка" — всплывающая подсказка
data-info="данные" — пользовательские атрибуты (data-*)
contenteditable="true" — можно редактировать
hidden — скрытый элемент
disabled — неактивный элемент формы
readonly — только для чтения

Правило: id должен быть уникальным на странице.
